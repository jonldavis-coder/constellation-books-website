Privacy

Draft. This privacy note is a working draft for the author site. It is not a finished legal policy.

This note describes the author website of Jonathan Lee Davis for the New Constellation trilogy. The site is a set of static pages. It does not ask visitors to create an account.

What this site stores

The pages do not include analytics, advertising, or a comment system. The site does not set its own cookies, and it does not keep a copy of form entries. When you use a request form, your browser opens an email to the address in the site configuration. That email is sent only if you send it from your mail app.

Scheduling

In-person and virtual visits can later be booked through Calendly, if those links are added to the site configuration. Until those links are filled in, the site does not load Calendly. If a Calendly scheduler is shown, Calendly handles the booking under its own privacy policy: Calendly privacy policy.

Amazon

Each book page has a button for an Amazon page. While that address is empty, the button is disabled and labeled “Coming soon to Amazon.” The site does not contact Amazon. If a link is added later, choosing it takes you to Amazon, which has its own privacy policy.

Hosting

The site is hosted on GitHub Pages. GitHub may process basic connection data as the host. GitHub’s privacy statement is at GitHub’s privacy statement.

Contact

Questions about this draft can use the contact page. The contact address is still a placeholder in the site configuration until it is replaced.

Changes

This draft was written on 7 November 2026. It may be replaced later.
