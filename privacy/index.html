Privacy

Draft. This privacy note is a working draft for the author site. It is not a finished legal policy.

This note describes the author website of Jonathan Lee Davis for the New Constellation trilogy: the back-cover description of New Constellation, the back-cover description of Circle of Stars, and the back-cover description of The Last Constellation. The site is a set of static pages. It does not ask visitors to create an account. Book clubs, students, and teachers each have a page of notes drawn from those descriptions.

What this site stores

The pages include Google Analytics. The analytics tag loads after the page has rendered, and it still records a page view. The pages do not include advertising or a comment system. The site does not set its own cookies for the request forms, and it does not keep a copy of form entries. Google Analytics may collect usage data under Google’s privacy policy. When you use a request form, your browser opens an email to the address in the site configuration. That email is sent only if you send it from your mail app.

The visit form on Meet the Author asks for a name, an email, an optional organization, a visit type (in person, virtual, or book club chat), a preferred date and time, an optional second choice, and an optional message. The contact form asks for a name, an email, and a message. Neither form is saved on this website.

Amazon

Each book page has a button for an Amazon page. While that address is empty, the button is disabled and labeled “Coming soon to Amazon.” The site does not contact Amazon. If a link is added later, choosing it takes you to Amazon, which has its own privacy policy.

Hosting

The site is hosted on GitHub Pages. GitHub may process basic connection data as the host. GitHub’s privacy statement is at GitHub’s privacy statement.

Contact

Questions about this draft can use the contact page or jon@verasail.com.

Changes

This draft was written on 7 November 2026, updated on 14 November 2026 to describe Google Analytics and the visit request form, and updated on 15 November 2026 to note that the analytics tag loads after the page renders. It may be replaced later.
